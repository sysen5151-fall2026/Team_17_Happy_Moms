# Happy Moms

A static, elegant website promoting a healthy pregnancy. Happy Moms shares gentle,
practical habits across nutrition, hydration, movement, rest, emotional wellbeing,
and prenatal care, and includes a short interactive Wellness Check-In that asks
mothers a few honest questions and reflects back personalized, judgment-free
suggestions.

## Pages

- `index.html` — Home page with an overview of the site and its mission
- `about.html` — Mission and values behind Happy Moms
- `tips.html` — Tabbed healthy-habit tips across six wellness topics
- `quiz.html` — The interactive Wellness Check-In questionnaire
- `contact.html` — Contact information and a demo contact form

## Structure

- `css/style.css` — Shared design system (colors, type, components)
- `js/main.js` — Shared behavior: nav toggle, scroll reveal, tabs, footer year
- `js/quiz.js` — Wellness Check-In quiz logic and scoring
- `assets/` — Site icon/favicon

## Running locally

This is a static site with no build step. Open `index.html` directly in a
browser, or serve the folder with any static file server, e.g.:

```
npx serve .
```

> Happy Moms provides general wellness information only and is not a
> substitute for medical advice from a licensed healthcare provider.
